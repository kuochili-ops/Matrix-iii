# 🟢 The Matrix Rain - 照片融化數位瀑布雨 3D 矩陣

一個基於 **Three.js** 與 **WebGL** 開發的互動式 3D 賽博龐克視覺特效網頁。本專案能將平滑的高畫質照片（預設載入 `DSCF2875.jpeg`），透過多條向下掃過的數位雨瀑布線，漸進式地解碼侵蝕為具備 3D 浮雕層次感、動態跳動且持續流動的 **駭客任務（The Matrix）數字代碼雨**，並支援畫幕高畫質自動錄影下載功能。

🌐 **線上演示 Demo**：[https://kuochili-ops.github.io/Matrix-iii/](https://kuochili-ops.github.io/Matrix-iii/)

---

## ✨ 專案亮點與特色

- 📷 **自動載入與自訂照片**：預設自動載入同目錄下的 `DSCF2875.jpeg` 照片，並支援上傳任意自訂圖片。
- 🌊 **瀑布線漸進融化解碼**：點擊啟動後，多條數位瀑布雨浪頭會由上往下掃過照片，平滑將照片轉換為 3D 數字陣列。
- ⚡ **持續無間斷動態雨流**：數碼化後的圖案區域**絕不靜止**！包含字元隨機閃爍跳動與持續貫穿傾瀉的亮綠色瀑布浪頭。
- 🔠 **超清晰向量中文字**：採用獨立 HiDPI 高解析度 Canvas 採樣與雙重發光特效，確保「白六問候親友們」等中文字筆劃清楚好讀不混淆。
- 🧊 **灰階深度 3D 浮雕**：利用照片明暗灰階（Gray Value）動態計算 $Z$ 軸突起高度，支援 360 度視角旋轉與縮放。
- 🎥 **一鍵自動錄影存檔**：整合 MediaRecorder API，完成照片轉換與 3 秒持續流動後，會自動停止錄影並下載檔名為 `白六駭客任務照片版.webm` 的影片。
- ⚙️ **選單自動收合與獨立按鈕**：提供「僅觀賞效果」與「觀賞 + 自動錄影存檔」雙按鈕，啟動時自動收合控制選單，呈現完美全螢幕視覺。

## 🛠️ 技術架構 (Tech Stack)

- **前端渲染**：[Three.js](https://threejs.org/) (r128) - 3D 場景、Sprite 粒子系統與 Fog 霧化
- **控制器**：OrbitControls - 支援滑鼠/觸控 360 度旋轉與滾輪縮放
- **畫布採樣**：HTML5 Canvas 2D API - 高清圖像採樣與雙倍向量字體繪製
- **視訊錄製**：MediaRecorder API - 瀏覽器原生畫布即時錄影 (WebM 格式)
- **樣式與佈局**：HTML5, CSS3 Glassmorphism (毛玻璃質感介面)

## 🚀 快速上手 (Quick Start)

### 1. 本地端執行
本專案為純單一 HTML 架構，無需不安裝繁重的 Node.js 環境：
1. 將本儲存庫複製 (Clone) 或下載至本地端。
2. 確保照片 `DSCF2875.jpeg` 與 `index.html` 放置於**同一目錄下**。
3. 使用任何本地 Web 伺服器開啟（例如 VS Code 的 `Live Server` 套件），即可直接在瀏覽器預覽。

### 2. GitHub Pages 佈署
1. 將專案推送至您的 GitHub 儲存庫（如 `Matrix-iii`）。
2. 至儲存庫的 **Settings** -> **Pages**。
3. 將 Source 設定為 `main` 或 `master` 分支的 `/ (root)` 目錄並儲存。
4. 幾分鐘後即可透過 `https://<username>.github.io/Matrix-iii/` 訪問！

## 🎛️ 控制面板說明

點擊右上角的 ⚙️ 圖示可展開/收合調校選單：

| 控制項目 | 功能說明 |
| :--- | :--- |
| **選擇自訂照片** | 隨時上傳您自己的照片替換預設的白狗照片 |
| **圖案下方的文字** | 自訂圖案下方顯示的主標題（預設：`白六問候親友們`）與副標題 |
| **⚡ 啟動照片瀑布雨 (不錄影)** | 重置照片並執行瀑布雨融化解碼過程，自動收合選單（不錄影） |
| **🎥 啟動照片瀑布雨 + 自動錄影** | 執行轉換並開啟錄影，完成後自動下載 `白六駭客任務照片版.webm` |
| **解碼轉化速度** | 調整瀑布雨掃過侵蝕照片的速度（預設 0.5x 慢速質感） |
| **3D 浮雕突起高度** | 調整照片明暗度轉換為 3D $Z$ 軸立體突起的深度 |
| **3D 點陣密度** | 調整圖片數碼化後的粒子解析度與顆粒大小 |
| **主題配色** | 提供經典螢光綠 (Matrix)、賽博霓虹藍、駭客金與單色高亮四種主題 |
